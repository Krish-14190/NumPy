# NumPy Learning – 3 Phases

## About the Project
This repository contains my NumPy learning journey, organized into three phases using Jupyter Notebooks. It covers fundamental to practical NumPy concepts with hands-on examples and exercises.

## Technologies Used
- Python
- NumPy
- Jupyter Notebook

## Project Structure

```text
NumPy/
│
├── Phase 1.ipynb
├── Phase 2.ipynb
├── Phase 3.ipynb
│
└── README.md
```

## Learning Phases

### Phase 1 – NumPy Fundamentals
- numpy array and basics
- list vs numpy 
- creating array from scratch
- vector , matrix and tensor
- Array Properties
- Reshaping Array

### Phase 2 – Array Operations
- slicing in array
- Sorting
- filtering
- filter with mask
- fancy indexing vs np.where()
- adding & removing data
- comatibility

### Phase 3 – Practical NumPy
- Practical Sales Data Analysis

## How to Run
1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Install NumPy:
   ```bash
   pip install numpy
   ```
3. Open Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
4. Run the notebooks phase by phase.

## Objective
The objective of this project is to build a strong foundation in NumPy and understand how to perform efficient numerical computations and data manipulation using Python.
